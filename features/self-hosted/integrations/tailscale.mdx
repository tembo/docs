## Prerequisites

Complete the [shared prerequisites](/features/self-hosted/integrations/overview). You need tailnet administrator access and outbound connectivity to Tailscale from your instance and sandboxes. Joining the host VM to a tailnet does not automatically join its sandboxes.

## 1. Prepare the tailnet

Follow the [Tailscale prerequisites](/integrations/tailscale#prerequisites) to create a dedicated device tag and access policy. Create an OAuth client with **Auth keys → Write** and permission to issue keys for that tag.

Limit the tag's network access to the internal hosts and ports your agents need.

## 2. Connect from your instance

1. Open **Settings → Integrations** and install Tailscale.
2. Enter a connection name, OAuth client ID, client secret, and device tags.
3. Save the connection after credential validation succeeds.

These credentials belong in the integration form, not a browser OAuth app configuration. No public webhook or redirect URI is required for this connection.

## 3. Verify

Start a new session and ask the agent to use Tailscale to access an allowed test host. The integration connects on demand with a single-use ephemeral key; a fresh session needs its own connection.

If joining succeeds but the resource is unreachable, check the device tag, access policy, subnet routes, and DNS. See [Tailscale usage](/integrations/tailscale) for userspace networking details.
