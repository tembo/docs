## Prerequisites

Complete the [shared prerequisites](/features/self-hosted/integrations/overview). Prepare a Google Cloud project ID and a dedicated service account JSON key with permission to run the required queries and read the intended datasets. Your instance and sandboxes need outbound access to Google authentication and BigQuery APIs.

## Connect BigQuery

1. Open **Settings → Integrations** on your own instance.
2. Select **Connect** next to BigQuery.
3. Enter the Google Cloud project ID and service account JSON key, then save.

No instance-wide OAuth application or callback URL is needed. This is a data connection, independent of whether you deployed Tembo on Google Cloud.

## Verify

Start a new session and ask Tembo to list or query a small test dataset. Confirm the results belong to the intended project.

If authentication succeeds but a query fails, check both query-job permissions and dataset access. Keep the service account scoped to the datasets you need, and review queries that could scan large tables. Update the saved connection when rotating its key. See [BigQuery usage](/integrations/bigquery).
