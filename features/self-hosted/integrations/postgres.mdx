## Prerequisites

Complete the [shared prerequisites](/features/self-hosted/integrations/overview). Prepare a connection string for the target database, a dedicated database user, and a network path from the agent sandbox to that database.

<Note>
  This connects a database for agents to query. It does not change the PostgreSQL database used internally by the Tembo platform.
</Note>

## Connect Postgres

1. Open **Settings → Integrations** on your instance and select Postgres.
2. Enter the target database's connection string and save it.
3. For a private database, configure routing from sandboxes or use [Tailscale](/features/self-hosted/integrations/tailscale) or [OpenConnect](/features/self-hosted/integrations/openconnect).

Do not assume `localhost` in a connection string refers to your host VM: database tools run in the sandbox. Use an address reachable from there, with the database's required TLS settings.

## Verify

Start a new session and ask Tembo to inspect a test schema or run a read-only query. Check DNS, firewall rules, TLS trust, and database grants if it fails.

Use read-only credentials for read-only tasks. Grant write privileges only when the workflow requires them, and review migration proposals before applying them. Performance analysis may also require the `pg_stat_statements` extension; see [Postgres usage](/integrations/postgres).
