---

<Warning>
  The Raycast extension does not expose a custom API or frontend base URL setting. Its hosted endpoints mean entering a self-hosted API key alone is not a supported self-hosted setup.
</Warning>

## Before installing

The [Raycast guide](/integrations/raycast) describes the hosted service. Do not enter your self-hosted instance's API key into that extension expecting requests to be sent to your instance.

Contact [support](/support) if you need a self-hosted-compatible extension. A compatible build would need to target your API and frontend URLs and match the API supported by your release.

## Alternative

Use your instance's web interface or [API](/api) to create and inspect sessions. For browser pull request redirects, the [Chrome extension](/features/self-hosted/integrations/chrome-extension) supports a custom Tembo base URL.
