## Prerequisites

You need access to sandbox settings on your [self-hosted instance](/features/self-hosted/overview), an Infisical token scoped to the required secrets, and sandbox connectivity to the Infisical API. Verify that your sandbox image includes the Infisical CLI before using the workflow.

## Configure sandbox secrets

1. Open **Settings → Sandbox** on your instance.
2. Add `INFISICAL_TOKEN` as a sandbox environment variable.
3. Optionally set `INFISICAL_PROJECT_ID`, `INFISICAL_ENV`, and `INFISICAL_SECRET_PATH` for your project defaults.
4. If you run your own Infisical server, set `INFISICAL_API_URL` to that server's API address and ensure the sandbox trusts its TLS certificate.
5. Save and start a new session.

These are sandbox environment variables, not provider OAuth keys in `/var/lib/tembo/config.json`.

## Verify

Use the [Infisical command workflow](/integrations/infisical#usage) to run an application that needs an injected secret. Confirm that it starts successfully without printing the secret or writing it into a committed file.

If the CLI cannot infer your project, supply the project ID as described in the usage guide. Explicit CLI flags override environment defaults. Scope the token narrowly and update the sandbox setting when rotating it.
