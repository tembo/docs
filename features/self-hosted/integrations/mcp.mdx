## Prerequisites

Complete the [shared prerequisites](/features/self-hosted/integrations/overview). You need access to the provider account or MCP server, permission to authorize its tools, and network connectivity from your API and sandboxes to the server.

Self-hosting Tembo does not self-host a provider's MCP service. Remote connections still send tool requests to that service. Review data handling and permissions before connecting sensitive systems.

## OAuth on your own domain

Tembo uses the provider's MCP authentication flow. Its callback for a standard self-hosted deployment is `https://tembo.example.com/api/oauth/mcp/callback`, derived from your API base URL.

If a provider requires a pre-registered OAuth client, register this callback and use the connection's OAuth client configuration. Do not reuse credentials registered only for hosted Tembo callbacks. [HubSpot](/features/self-hosted/integrations/hubspot) has dedicated instance configuration for its MCP Auth App.

If authorization is pending, complete or retry the authorization from your instance. Check redirect registration, API base URL, and provider restrictions if authorization fails.

## Custom and private servers

Use **Custom MCP** to add an HTTP, SSE, or stdio server. The [MCP configuration guide](/integrations/mcp#custom-server-transport-types) provides the accepted JSON formats.

- **HTTP or SSE:** enter the server URL and any required authentication headers. For private endpoints, configure network access and TLS trust from the API and sandboxes.
- **Stdio:** provide the executable, arguments, and environment variables. The executable and its dependencies must exist in the sandbox image, not just on the Tembo host.
- **Visibility:** workspace administrators can choose a personal or shared connection; non-admin connections are personal. Match visibility to the data the credentials can access.

Start with a read-only tool call and confirm the returned data belongs to the expected account. Avoid putting secrets in committed configuration examples or asking agents to print credentials during verification.
