---
title: 'Self-hosted setup'
description: 'Connect the Tembo SDK and API reference to your self-hosted deployment.'
---

Self-hosted Tembo uses the same API operations and schemas as Tembo Cloud. Choose
the server for your deployment when you use the [API Reference](../):

- Tembo Cloud: `https://api.tembo.io`
- Self-hosted: `https://{host}/api/public-api`

Generate an API key from **Settings > API Keys** in your self-hosted dashboard,
then configure the SDK with your deployment's API base URL:

```javascript
import Tembo from '@tembo-io/sdk';

const client = new Tembo({
  apiKey: process.env.TEMBO_API_KEY,
  baseURL: 'https://tembo.example.com/api/public-api',
});
```
