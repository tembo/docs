---
title: 'Self-hosted setup'
description: 'Configure API access for your self-hosted deployment.'
---

Self-hosted deployments use the same API operations and schemas as the Tembo API. Choose
the server for your deployment when you use the API Reference:

- Tembo API: `https://api.tembo.io`
- Self-hosted: `https://{host}/api/public-api`

Generate an API key from **Settings > API Keys** in your self-hosted dashboard,
then replace `tembo.example.com` with your deployment's hostname:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://tembo.example.com/api/public-api/v1/sessions
```
