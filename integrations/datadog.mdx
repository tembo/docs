Query Datadog metrics, logs, traces, monitors, and incidents through MCP.

## Prerequisites

You need access to your Tembo organization and a Datadog account and the Datadog site that hosts your data. Review the provider permissions before granting access to your data.

## Installation

1. Open **Settings → Integrations** in Tembo.
2. Select **Datadog**, choose the site that hosts your data, and start the installation.
3. Complete the provider authorization if prompted. Review the requested access and select the intended account or workspace.
4. Confirm the connection is ready before starting a new session.

The catalog server defaults to US1 at `https://mcp.datadoghq.com/v1/mcp`.

If authorization requires a pre-registered OAuth client, follow the [MCP authentication instructions](/integrations/mcp#advanced) and register the callback shown in the connection dialog.

## Usage and verification

Start a new session and ask Tembo to read a test monitor or a small set of recent metrics. Confirm the tools are available and that any returned account data belongs to the account you intended to connect.

## Access and troubleshooting

Select the Datadog site matching your account during installation. Connecting to the wrong regional endpoint does not grant access to data in your actual site.

If the connection remains pending, return to **Settings → Integrations** and finish authorization. If tools do not appear, confirm the connection was saved and start a new session. See [MCP troubleshooting](/integrations/mcp#advanced) for authentication and connectivity checks.
