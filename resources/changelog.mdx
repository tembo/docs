Tembo ships continuously. This page highlights the user-facing features from each week's release. For the full history of every change, see our [status page](https://status.tembo.io) and release notes.

## August 12, 2026

- **Bring your own OpenRouter key:** Connect an OpenRouter API key to unlock its full catalog of models using your own account, alongside existing BYOK providers.
- **Faster "Open PR":** Opening a pull request no longer waits for your sandbox to boot back up — Tembo now opens PRs directly from your latest saved changes.
- **Multi-file browsing in sessions:** Workspace files now open in sidebar tabs, so you can reference several files at once instead of switching back and forth.
- **Deeper GitLab integration:** Added GitLab service account support and expanded automation triggers, plus more reliable macro resolution and credential refresh for GitLab-connected repos.
- **Codex usage at a glance:** Your connected Codex account's usage and quota now show up right in Tembo.
- **"Review on Tembo" for Slack:** Teams can opt in so the completion button on Slack PR notifications opens the review in Tembo instead of the source Git provider.
- **Public API session control:** Added a public endpoint to stop a running session programmatically, for teams building on top of the Tembo API.
- **Polished session chat:** Refined message scrolling, activity grouping, and the composer for a smoother day-to-day chat experience.

Also various bug fixes and improvements as always :)
