# Daily changelog: August 25, 2026

**Version:** `2026.08.25`
**Release date:** August 25, 2026
**Release window:** Changes merged on August 24, 2026
**Breaking changes:** None

## Summary

This release updates Tembo documentation to reflect the current project creation workflow, clarify GitLab merge request coverage, and improve the Tailscale integration page visuals. No user migration or developer action is required.

## Added

- Added a Tailscale integration banner to make the Tailscale setup guide easier to recognize and scan. See [PR #716](https://github.com/tembo/docs/pull/716). Contributor: Darren Baldwin.

## Changed

- Updated the project creation guide to explain that Tembo automatically starts building an environment for each selected session size after you create a project. This removes the outdated manual **Build environment** step and should reduce setup confusion. See [PR #713](https://github.com/tembo/docs/pull/713).
- Clarified that GitLab `@tembo` comments work on Tembo-created merge requests, team-created merge requests, and merge requests from outside contributors on activated repositories. See [PR #712](https://github.com/tembo/docs/pull/712).
